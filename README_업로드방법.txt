KLPGA 골프 브랜딩 마스터클래스 교육생용 웹페이지

1. 압축파일을 풀어 주세요.
2. GitHub에 새 저장소를 만들거나 기존 저장소를 엽니다.
3. 반드시 압축을 푼 폴더 안의 index.html, data.json, slides 폴더를 저장소 최상위에 업로드합니다.
   (폴더를 통째로 업로드해서 index.html이 한 단계 안으로 들어가지 않도록 주의)
4. 저장소 Settings > Pages > Build and deployment > Deploy from a branch 선택.
5. Branch: main, Folder: /(root) 선택하고 Save.
6. 제공된 https://아이디.github.io/저장소명/ 주소로 접속합니다.

외부 API 및 별도 설치가 없는 정적 웹사이트입니다.
83개 슬라이드는 webp로 저장되어 있고, 48종 실습 프롬프트는 data.json에 저장되어 있습니다.
실습 정보는 교육생 본인의 브라우저에만 저장됩니다. 서버로 전송되지 않습니다.
